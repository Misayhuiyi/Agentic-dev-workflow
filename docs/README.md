# 项目文档导航

初始模板只提供本导航。建项时由 `project-kickoff` 结合真实事实按需创建文档，不预建空项目目录、不填写虚构命令或测试成绩。已有项目的 README、文档索引、代码和配置优先；现有路径已合理时继续使用，不创建第二套 spec/plan。

| 默认位置 | 何时创建、记录什么 |
| --- | --- |
| `docs/project-context.md` | 首次建项或已有项目接入后：目标、实际技术栈、命令来源、模块地图、活动任务指针和未验证项；建议不超过 8 KiB |
| `docs/tasks/index.md` | 有活动任务时：任务 ID、状态、负责者、worktree 和文件指针；仅整合者更新，真实分支在恢复时核对 |
| `docs/tasks/<task-id>.md` | 需要执行和跨会话恢复时：合同、当前事实、相关/排除路径、验证指纹、风险及下一步；使用受验证 machine block |
| `docs/specs/` | 设计需要书面批准时：目标、验收、非目标、契约和批准依据；未实现部分标明计划 |
| `docs/plans/` | 复杂实施需要分解时：唯一权威计划；范围改变才修订，不为同一任务重复建计划 |
| `docs/adr/` | 重要且长期影响的决策：背景、选项、取舍；后继决策以“已替代”关联旧记录 |
| `docs/iterations/` | 重要迭代结束：目标、变化、决策、验证/Benchmark、问题、遗留和下一步；小改可无需独立日志 |
| `docs/operations/` | 实际需要发布、迁移、回滚或事故处置时：环境、授权、执行证据、恢复和观测 |

读取顺序是项目上下文 → 活动索引 → 指定任务 → 必需的 spec/plan/ADR → 相关代码与证据。代码和配置是实现事实的权威，spec 是批准意图，状态文件只是恢复线索；冲突时标记陈旧并重新核对。验证记录绑定提交或相关文件指纹；变更后重新验证。

## 人和 Agent 共用同一份事实

业务项目的根 README 说明项目用途、启动方式与文档入口，链接本导航和真实的项目上下文。项目上下文提供一屏摘要：当前能力、里程碑、已实现与已批准未实现的区别、已知限制，以及活动任务和证据的链接。它不复制每个任务的动态状态。初始模板中的 README 是使用说明；首次建项时按真实项目改写，不另建第二个首页。

任务文件首行 JSON 是唯一动态正本。其正文可以有由 `project_status.py --format markdown` 生成的可读快照，供人直接查看；该区是派生展示，不单独手改。更新机器块后重新生成，只替换标记区并保留背景、证据和交接备注。用 `--check-view` 检查展示是否与机器块和当前工作区一致；快照不是实时监控，换会话仍需核对实际文件。没有 Python 时手工核对同样六项并注明未自动核验，不虚构通过。

索引除机器块外仅提供指向真实任务文件的可点击链接，不另存一套详细进度。模板中的 `RAG-003`、`src/example.py` 等都是示例，建任务时必须替换为真实标识和路径。

## 更新责任与时机

| 权威位置 | 谁维护、何时更新 |
| --- | --- |
| README / project-context | 当前整合者在用途、里程碑、真实命令、模块或文档入口发生变化时同步 |
| task-state | 任务负责人在实质进展、范围、验证、阻塞、暂停或交接变化时更新机器块及可读快照 |
| 活动索引 | 整合者在任务进入/退出活动集合、负责人或 worktree 改变后核对并更新 |
| spec / plan | 原任务负责人维护唯一合同；只有范围或实施步骤变化时修订，保留批准依据 |
| iteration / ADR / operations | 负责人在重要迭代、决策或实际运维事件发生时记录，链接真实任务与证据 |

当场完成、没有持久事实变化的小改可以只在交付回复中留证据，不强制新建任务或日志。原本很小的工作一旦未完成、受阻、暂停或需要换会话，在已有写入授权内也要先创建最小 task-state 并登记索引；不需要因此补造 spec/plan。若本轮只读或无法写入，输出六项快照、建议保存路径，并明确“尚未持久化”，不能承诺下一会话自动知道。

完成任务标记 done、保留原路径及证据指针，再从活动索引移出。重要迭代记录是关闭时的历史快照，遗留事项只链接仍活动的任务；已接受 ADR 保留正文，以状态及后继链接表达替代。只有历史数量妨碍导航时才增加归档索引，不预建目录或复制正文。不把完整聊天、diff、日志或敏感信息塞进“记忆”；未完成项不得在归档时消失。共享模板见 [工作流模板](../.ai-workflow/templates)，路由见 [ROUTING](../.ai-workflow/ROUTING.md)，人工使用入口见 [README](../README.md)。
