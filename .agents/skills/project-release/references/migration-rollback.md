# 迁移、回退与数据恢复

列前后版本、读写方、数据/索引范围、真实脚本、幂等与中断恢复语义。验证混合版本兼容及实际执行顺序，不能从成功构建推导迁移安全。

备份存在、备份完整性、隔离恢复演练是不同证据。应用回滚不恢复已删列/覆盖数据；恢复未知时停止破坏性步骤。明确不可逆性、停止阈值、恢复负责人和授权范围。

索引变化分清源快照、索引版本和查询配置，避免混用不兼容向量。全量重建、旧数据清理、外部费用都须在既有授权内。

中断后核查已执行阶段，不能盲目重复非幂等操作；记录动作和结果，恢复仍按实际环境和权限执行。

涉及 Agent/工具外部动作时，单列已经发生、在途及结果不确定的发送、写入或资源操作。回滚代码、关闭开关或停止 Agent 都不能撤销这些动作；在执行前确定幂等/去重依据、确认/对账方式及可行的补偿路径。结果不确定时先核实，不盲重试；补偿可能产生新副作用，核对授权、负责人和停止条件后才执行。无法补偿的影响明确交接，不能记作已恢复。
