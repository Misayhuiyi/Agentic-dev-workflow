# AI 与性能对照

先固定数据快照/哈希、样本数量/划分、标注和指标；基线与候选使用可比环境。记录代码及工作区指纹、模型/可得版本、提示、配置、采样随机性与工具设置。RAG 还需文档、分块、embedding、索引、检索/重排版本。

按实际目标选择正确性、召回/引用支持、任务成功、越权工具调用、失败率、吞吐及延迟。没有标签不能伪造 recall；模型裁判要记录版本/提示并抽样人工核验。

记录样本规模、重复次数及波动，费用上限、调用数和停止条件。未经授权不上传敏感数据或发起收费评测。延迟/费用基于实际测量，说明测量窗口和估算方法。

外部模型或服务不可用时分别报告可做的局部检查与未执行的真实对照；不能用模拟输出冒充质量改进。改了数据或模型要明确混杂因素，未运行写未运行，不挑有利样本。

最小评测输出块不得用实现计划代替评测合同，应显式命名：

- 固定输入：数据哈希、样本/划分/标注/指标，代码与工作区指纹，模型/提示/配置/随机性/工具；RAG 逐项列文档、分块、embedding、索引、检索与重排版本。
- 可用证据：已执行的局部检查及实际结果；外部对照单列已执行或未执行原因。
- 边界：费用上限、调用数上限和停止条件。缺值逐项写未知，不用“按固定条件”或“按预算”概括。
