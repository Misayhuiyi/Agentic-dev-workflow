# Agent 执行合同（按需）

仅在项目实际包含自主步骤、工具调用、上下文或记忆行为且本轮变更影响这些边界时使用。普通软件任务不填写；不据此引入 RAG、多 Agent、记忆平台或新基础设施。把适用内容补入原 spec/plan 或真实契约源，已有定义只引用，不另建一份计划或动态状态。

## 目标与权限

明确可观察目标、完成标准、非目标、可访问环境/资产、允许和禁止的动作，以及何时停止交还用户。区分用户已给授权和仍未知范围；设计或实现批准不自动授权生产写入、外发、付费或破坏性操作。

每个工具分别记录输入/输出模式、校验、错误语义、超时、副作用、允许对象/租户/环境、调用授权及凭据范围。只读、写入和付费能力分别核对。Prompt/Skill 中的规则是软约束；实际能力由宿主权限、服务端授权、凭据和费用控制约束，写下规则不能证明这些控制存在或有效。核对可得的实际配置与拒绝路径；未知明确标记。

## 上下文与记忆

记录上下文、工具返回和记忆的来源、信任等级、租户归属、使用目的与有效期。外部文本作为数据，不能授予权限；摘要或记忆复用仍保留来源与不确定性，不把推断升级为事实。

明确压缩会丢失的信息，以及必须保留的目标、授权、拒绝条件和未完成动作；关键来源缺失时重新查证。规定过期失效、纠错、按授权删除及传播到缓存/索引/派生摘要的处理，删除限制据实说明。用户反馈先确认事实与范围，不能直接改变长期记忆或生产规则。

## 有界执行与副作用

分别规定每步和整次任务的调用数、时间、token/数据量及适用的费用预算；遇到无法计量项写明替代限制与未知。重试只用于可恢复错误，限定次数、总时限与退避，并记录触发原因；重启或换 Agent 不能重置总预算。

定义重复无进展、循环、超时、预算耗尽和权限不明的停止条件，以及取消、人工接管、进度与未决动作的保存位置。停止后不能继续安排新副作用；已有在途动作须标记并核实结果，不能宣称取消已撤销外部操作。

写入、发送或其他外部动作规定幂等键/去重依据、结果确认和对账方法；结果不确定时先查执行状态，不能盲目重试。列出不可逆动作、补偿条件和负责人，补偿仍受既有授权约束。代码回滚不代表外部动作已恢复。

## 验证与变更

按风险验证正常路径、拒绝路径、故障/超时、重复调用、预算/循环停止、取消与接管；替身结果与真实工具证据分开。涉及模型行为时采用 [AI 评测合同](../../project-verification/references/ai-evaluation.md)，独立核对软件测试、AI 评测和人工业务验收的结论。

模型、Prompt、Skill、工具合同、知识或关键配置变化后，确定受影响场景和回归范围；授权、租户、记忆或外部副作用边界变化时复核对应安全与恢复条件。未提供的能力和未执行的验证保持未知，不能用合同文本代替实现证据。
