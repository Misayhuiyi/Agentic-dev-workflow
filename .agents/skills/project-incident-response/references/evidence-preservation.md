# 有界证据保护

记录可靠 UTC 时间、事件顺序、候选/配置变化、影响摘要、请求关联和必要日志片段，注明来源与置信度。时间未知就写未知，不以聊天推测补齐时间线。

采集范围限当前事故与获准环境，限制时间窗口、条目数和体积；保留来源引用，不无界复制日志、数据库或环境变量。密钥、个人数据和敏感 payload 脱敏，避免把事故证据变成泄露渠道。

操作前保存必要定位证据；清理、重启或回滚可能破坏现场，需确认动作授权及恢复风险。未授权不删数据，不能为“验证”攻击外部系统。

输出事实/假设/未知、已保存证据和缺口；后续 systematic-debugging 复用这些证据，不把未确认推断当根因。
