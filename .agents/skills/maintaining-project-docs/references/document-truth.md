# 事实、预期与历史

当前代码/配置定义实际实现，已批准需求/契约定义预期，测试/运行记录提供有限观测。冲突要明确具体差异，不将聊天或状态摘要置于实际证据之上。

计划能力标计划/未实现；假设附验证方法；未知与未验证明确写出。提交 SHA 不能代表 dirty 工作区，验证绑定相关文件指纹。

ADR 保留当时背景，以 superseded/已替代和后继链接表达演进。修正笔误可以，伪造历史、删除失败实验、编造测试日期、提交或 benchmark 不可以。

只创建有实际内容和维护用途的记录。不复制完整日志/diff/聊天，不预建空 ADR/runbook。文档命令引用真实配置；核对有权限且无额外副作用后才执行，不为验证文本擅自生产操作。
